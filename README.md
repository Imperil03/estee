# SEO-кейс клиники «Кожа»

Публичная интерактивная презентация alexandrov digital agency: как SEO стало одним из основных источников обращений для клиники косметологии.

Сайт: https://imperil03.github.io/estee/

В репозитории находятся только файлы готовой страницы:

- `index.html`, `styles.css`, `script.js`;
- локальные WOFF2-шрифты;
- оптимизированные WebP-изображения и скриншоты доказательств;
- SVG-favicon.

Рабочие таблицы, исходные аналитические выгрузки и внутренние материалы в публичный репозиторий не включены.
