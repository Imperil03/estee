# Кейс клиники «Кожа»

Публичная клиентская версия кейса Vitamin Digital Agency: SEO, медицинский контент, UX и аналитика для клиники косметологии.

- `index.html` - основная интерактивная версия.
- `kozha-case-vitamin.pdf` - версия для пересылки и печати.
- `assets/` - только изображения, использованные в кейсе. Исходные аналитические выгрузки в репозиторий не включены.

Данные на странице показаны в относительных величинах. Методика и периоды описаны в разделе «Что стоит за процентами».
